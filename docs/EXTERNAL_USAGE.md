# External usage

This file records Barkeep usage by people other than the author. It is kept
apart from the author's own runs, which live in
[`deployments/testnet.json`](../deployments/testnet.json) and
[`deployments/testnet-v09.json`](../deployments/testnet-v09.json). Do not copy
rows between the two, and do not total them together.

**Today this table is empty. No one other than the author has used Barkeep.**

## Rules for adding a row

A row is added only when all of these are true:

1. **The participant generated the signing key themselves**, on their own
   machine (for example `stellar keys generate`). The author never generated
   it, never held it and never saw it. A key handed out by the author makes
   the row team-generated, and it does not belong here.
2. **The transaction is on chain and can be looked up.** The tx hash resolves
   on a public explorer. A screenshot does not count.
3. **The participant consented in writing to this listing.** The consent says
   what is published: the public address, the date and the tx hash. No name
   is published unless the participant asks for it.
4. **Nothing private is stored here.** Public addresses and hashes only. The
   consent record is kept outside the repository. This file names only where
   it is kept.

If a row is later found to break any rule, delete it and note the deletion
below the table with the date and the reason.

Field notes:

- **What they did**: one of `opened tab`, `paid (x402)`, `refused on chain`
  (with the error code), `closed tab`, or `ran kit end to end`. Use one row per
  transaction.
- **Tx hash**: the full 64-hex hash, linked to
  `https://stellar.expert/explorer/testnet/tx/<hash>` (or the public network
  explorer for mainnet).
- **Consent**: an identifier for the signed consent. Never the form contents.
- **Event**: for example `Türkiye chapter workshop, 2026-MM-DD`, or
  `independent` if the person found the repo on their own.
